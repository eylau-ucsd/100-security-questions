### Description

This problem is similar to [12-security-questions](https://github.com/eylau-ucsd/12-security-questions), but instead of 12 questions with 10 possible options each, of which 10 of them have to be chosen and answered correctly, there are now 100 questions with 2 options each, of which only 90 of them have to be chosen and answered correctly.
